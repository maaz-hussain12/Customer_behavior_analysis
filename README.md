# Customer_behavior_analysis
This project showcases a complete end-to-end data analytics workflow from cleaning and exploring raw data in Python to analyzing business insights using SQL and visualizing key trends in Power BI. It demonstrates how data can be transformed into meaningful insights that support smarter, data-driven business decisions.
Technologies used: Python, PostgreSQL, Power BI


## How to Use
1. Open the Jupyter Notebook

   * Run the `customer_behavior.ipynb` file to clean, explore, and load data into PostgreSQL.

2. Open the SQL File

   * Execute the queries in `customer_behavior.sql` to analyze customer data and extract business insights.

3. Visualize in Power BI

   * Connect Power BI to your PostgreSQL database and open `customer_behavior.pbix` to explore interactive dashboards and key trends.
